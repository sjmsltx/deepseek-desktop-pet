桌宠「好感度与成长系统」设计方案

2026-08-28 · 项目：deepseek-desktop-pet · 参考：whale-girl / DyberPet / LiveGalGame / dsh-pet

〇、现状盘点

现有能力与方案关系
双角色独立模型/对话/记忆好感度按角色隔离，人设进化按角色独立
长期记忆（memorize + memory.json）事实记忆层保留，新增「事件记忆（回忆日志）」层
API 统计（api_stats.json）余额气泡直接复用费用数据
20+ 动作素材 + Live2D扩展动作状态机即可
主动关心系统关心频率由「人设阶段」统一调制
核心约束：desktop_pet.py 已是 306KB 单文件 → 新系统独立模块化，主文件只接线。

一、总体架构

desktop_pet.py（主程序，仅接线）
 ├── affection_engine.py   ← 好感度引擎（纯逻辑无 UI，可单测）
 ├── memory_events.py      ← 回忆日志（事件记忆）
 ├── pet_minigames.py      ← 小游戏（注册式可扩展）
 ├── affection_ui.py       ← 进度条/气泡动画/小游戏窗口
 └── （现有）chat_memory / memory / api_stats / assets

原则：引擎与 UI 分离——引擎层纯数据逻辑，UI 层只做展示交互。

二、好感度数值系统（核心）

双轴模型

轴范围含义影响
好感度 affection0~200（初始 60）情感亲密度决定人设阶段、解锁动作/称号
等级 level / XP无上限陪伴资历荣誉称号、里程碑

事件表（纯积累，零衰减零惩罚）

事件好感防刷
对话+1单轮上限 +3
完成任务+5同一任务一次
喂食+2冷却 30 分钟
小游戏胜/参与+3 / +1每局
早安/晚安+2每天各一次
陪伴活跃+1/10min单日上限 +20

XP 曲线（whale-girl 公式）：xpForLevel(L) = 50·L·(L−1)/2；Lv2=50, Lv5=500, Lv10=2250。

称号 6 个：初次协作/勤劳伙伴/常驻伙伴/百炼成钢/越挫越勇/广结善缘。

存储 affection.json：双角色独立（flash/pro），含 cooldowns + daily 防刷字段。

三、人设进化（纵向维度）

阶段好感度关系定位prompt 注入
初见60~80礼貌助手称呼「您」、克制
熟悉80~110熟络朋友称呼「你」、开玩笑
亲密110~140亲密伙伴撒娇、昵称
依赖140~170心灵依靠主动关心升级
灵魂伴侣170~200唯一默契梗、特殊称呼

实施：ask_ai() 构建 system prompt 时按好感度注入「关系阶段」段 + 最近 3 条回忆；双角色独立；阶段只升不降。

四、记忆机制（三层架构）

层文件内容生命周期
对话记忆chat_memory*.json近期对话滚动压缩
事实记忆memory.json用户偏好（现有）长期重要度排序
事件记忆（新）memories.json共同经历时间线长期，上限 200 条滚动

回忆日志结构：{id, time, role, type, title, detail, emotion, affection_at}；写入时机：memorize 双写 / 里程碑 / 用户右键「📌 记住这一刻」；读取时机：prompt 注入最近 3 条 + 回忆相册 UI（Phase 3）。

五~九、交互功能逐个说明

余额动画气泡QLabel + QPropertyAnimation：角色头顶飘 -¥0.032 上浮渐隐 1.2s；费用>¥0.1 红色放大。复用现有 ApiStats 数据。
动作素材扩展asset() 状态机加新状态：撒娇/亲亲/胜利/沮丧/饥饿/送花——好感度联动触发；代码先行，素材后补（无素材降级现有动作）。
小游戏pet_minigames.py 注册式：首批石头剪刀布/猜数字/五子棋（minimax 深度2）；胜利 +3 好感。右键菜单「🎮 小游戏」入口。
好感度可视化右键「❤️ 关系」面板：进度条 + 阶段徽章 + 称号列表 + 最近变化；变化时飘 +2↑ 动效。
饱食度0~100 时间戳衰减（12h 归零），喂食 +40 并撒娇；低饱食只提示不惩罚（守零惩罚原则）。

十、实施分期

阶段内容工作量
Phase 1 核心affection_engine + 人设五阶段 + memories.json + 关系面板3-4 天
Phase 2 互动余额气泡 + 饱食度 + 3 款小游戏 + 动作状态3-4 天

十一、风险与边界

风险应对

人设注入影响质量阶段模板可配置，双角色可开关
素材缺失代码先行，无素材降级现有动作

与主动关心冲突关心频率由阶段统一调制
