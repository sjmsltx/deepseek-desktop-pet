DeepSeek 桌宠 · 便携版使用说明
=========================================

一、怎么跑
----------
1. 把整个 DeepSeekPet 文件夹解压到任意位置（例如 D:\DeepSeekPet）；
2. 双击 DeepSeekPet.exe 即可。
   注意：必须保持文件夹结构完整（exe 旁边的 assets/、plugins/、*.ps1 都要在），
   不要只把 exe 单独拷出来 —— 那样会没有立绘、没有技能、语音与 OCR 也会不可用。

二、第一次使用要填 API Key
--------------------------
编辑本目录下的 config.json（第一次运行后没有就参考 config.example.json 复制一份），
把 "deepseek_api_key" 填成你自己的 Key。Key 只在本地使用，不会发给本项目。
想换模型/换声音，看程序内「⚙️ 设置 → 模型 / 语音」页，那里有「❓ 怎么填自己的模型 / 自己的声音」。

三、能力一览
-----------
· 可选主区（3.0 新增）：聊天区底部「🗂 主区」按钮，把待办与状态放进一个窗口长期开着；
  不点它永远不会出现，默认用法与 2.9 完全一致
· 聊天 + 情绪立绘 + 好感度养成 + 主动关心
· 语音朗读（在线神经声线 / 离线声线 / 可接你自己的 TTS 服务；可调语速、可选朗读内容）
· 语音输入（四种后端，设置 → 语音 → 「🎙 语音输入设置…」）：
    系统（WinRT→SAPI，默认）／系统 Win+H 应急／本地 whisper.cpp／联网 ASR 接口
· 办公文档：做表格、生成报表、导出 PDF；生成 Word / PPT
· 技能包：可安装/卸载/启用禁用（设置 → 技能）；自带 4 个官方技能：
    办公报表 / PDF 工具 / 图片批处理 / 文件整理
· MCP 接入：可接外部 MCP 工具服务（设置 → MCP），写类工具调用前会先问你
· 治理：审计日志（logs/ 下按天）、额度限制（默认 20 次/分、300 次/天）、出网白名单
· 平台能力自检：设置 → 系统 页底部有 13 项能力清单

四、升级：换新版本时怎么不丢数据（重要）
--------------------------------------
升级时「不要删旧文件夹」，直接覆盖解压就行，你的数据都在里面，不会被覆盖掉。

具体做法：
1. 下载新版 zip 并解压；
2. 把解压出来的 DeepSeekPet 文件夹里的「所有内容」，复制到你现在正在用的那个
   DeepSeekPet 文件夹里；提示「是否覆盖」时选「是」（全部覆盖）；
3. 双击同一个 exe 继续用。记忆、好感度、待办、设置、API Key 都还在。

为什么这样是安全的：新版包里「不包含」你的个人数据（打包时已把 config.json /
memory.json / memories.json / todos.json / affection.json / api_stats.json /
logs 全部排除），所以覆盖只会替换程序文件，碰不到你的数据。

⚠️ 下面这三种做法会丢数据，别做：
· 先把旧文件夹删掉、再解压新包
  → 记忆、好感度、API Key 全部没了，且找不回
· 解压到一个新文件夹（例如 DeepSeekPet-v3.0.0）
  → 数据还在旧文件夹里，但新程序读不到，看着像"全丢了"（其实没丢：
    把下面那 7 项从旧文件夹拷到新文件夹即可）
· 合并时选"跳过已存在的文件"
  → 程序文件新旧混杂，可能打不开

💡 想更稳妥：升级前把这 7 项复制一份到别处（U 盘、网盘都行）——
   config.json、memory.json、memories.json、todos.json、affection.json、
   api_stats.json、logs 文件夹

五、安全须知（重要）
-------------------
1. 技能包与桌宠同进程运行：权限靠「清单声明 + 安装时你确认 + 静态扫描」把关，
   不是系统级沙箱。来源不明的包，先看权限卡片再启用。
2. 出网白名单约束的是第三方技能包；随程序自带的官方包视为已信任
   （目前仅 vision 需要联网调视觉模型，它不走白名单）。
3. MCP 是外部服务：工具的行为取决于对方。写类调用默认每次问你，不建议关掉这个确认。
4. 卸载技能包是移进 plugins/_uninstalled/（可找回），不会直接删除。

六、常见问题
-----------
Q：双击没反应 / 没有立绘？
A：确认是整个文件夹解压后运行，且 exe 旁边有 assets 目录；若仍无立绘，
   看看是否同时开了两个实例（同一时间只保留一个）。
Q：语音输入没反应？
A：默认走 Windows 自带识别，需要你手动打开「设置 → 隐私和安全性 → 语音」里的语音识别授权；
   不想开授权，可以在「设置 → 语音 → 🎙 语音输入设置…」里把后端换成「系统 Win+H 应急」，
   或配置本地 whisper.cpp / 你自己的 ASR 接口。
Q：办公功能报「缺少 pywin32 / 找不到 WPS」？
A：需要本机装有 WPS 或 Microsoft Office。
Q：审计日志与限额怎么调？
A：config.json 里 audit_log / tool_limits_enabled / tool_limits 可调；界面见「设置 → 技能 / MCP」。

七、卸载
--------
⚠️ 删之前先把数据备份出来（就是「四、升级」末尾那 7 项）——删掉文件夹等于删掉全部记忆。
备份好之后，直接删掉整个文件夹即可（程序不在系统里写任何东西，除了「开机自启」会在启动
文件夹放一个快捷方式，可在右键菜单里关掉，或直接删除该快捷方式）。
