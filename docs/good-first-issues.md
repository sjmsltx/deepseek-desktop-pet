# 🌱 Good First Issues（新手任务候选）

> 给第一次参与本项目的人准备的任务。每条都标了**难度**、**涉及文件**和**验收标准**——
> 满足验收标准即可提 PR，不需要读完整个项目。
>
> 参与前请读 [CONTRIBUTING.md](../CONTRIBUTING.md)；提交 PR 请用仓库的 PR 模板并附上验证方式。

---

## 1. 补齐英文 UI 文案（难度：🟢 容易 · 文档/国际化）

**背景**：项目 UI 文案需要在 `_TEXT_ZH` / `_TEXT_EN` 两份字典里成对出现（`self._t()` 取用）。随着功能增加，个别新文案只加了中文。

**任务**：找出 `_TEXT_ZH` 有、`_TEXT_EN` 缺的键，补齐英文；反之亦然。

**涉及**：`desktop_pet.py`（字典区）、`settings_ui.py`、`pet_minigames.py`

**验收**：
- [ ] 两份字典键集合完全一致（可写个小脚本或测试断言）
- [ ] 补齐的英文符合现有语气（Q 版桌宠口吻，不用直译腔）
- [ ] `python -m pytest tests/` 通过

---

## 2. 小游戏记住上次设置（难度：🟢 容易 · 体验）

**背景**：小游戏窗口每次打开都回到默认难度/默认大小；玩家每次都要重选。

**任务**：把"上次选择的难度 + 窗口尺寸"持久化到 `games_save/`（沿用现有暂停保存协议），下次打开时恢复。

**涉及**：`pet_minigames.py`（`BaseGame._add_difficulty` / `showEvent`）

**验收**：
- [ ] 选难度 → 关窗口 → 重开，仍是你上次选的难度
- [ ] 拖大窗口 → 重开，尺寸被记住
- [ ] 不破坏现有"暂停进度保存"（`python -m pytest tests/test_minigames_smoke.py`）

---

## 3. 给主题系统补一条"切换后重绘"测试（难度：🟡 中等 · 测试）

**背景**：项目已有"真绘制"冒烟测试（`tests/test_minigames_paint.py`），但**没有**"切主题后**重绘**是否正确"的断言。曾出现过"切主题只刷新部分界面"的真实 bug。

**任务**：写一个测试：构造游戏窗口 → `pet_theme.set_active({...})` → 断言窗口样式表/绘制结果已跟随新主题。

**涉及**：`tests/test_minigames_paint.py`（或新增文件）、`pet_theme.py`

**验收**：
- [ ] 测试在"故意让某控件不跟随主题"时会失败（先验证它能抓到问题）
- [ ] 覆盖至少 3 款游戏（含一个 `paintEvent` 画布类）
- [ ] `python -m pytest tests/` 全绿

---

## 4. 扩写 Live2D 管线文档（难度：🟡 中等 · 文档）

**背景**：`docs/live2d_pipeline.md` 是**全站访问量最高的文件页**（连续两周榜首），但目前偏流程提纲，缺少参数与踩坑细节。

**任务**：补图（流程图/GIF）、补参数表（模型目录结构、`model3.json` 关键字段、纹理尺寸建议）、补"常见报错 → 原因 → 解决"小节。

**涉及**：`docs/live2d_pipeline.md`（可新增 `docs/assets/` 配图）

**验收**：
- [ ] 新增流程图或截图 ≥2 张
- [ ] 关键参数以表格列出（不再只有文字描述）
- [ ] 至少 5 条真实踩坑条目（可来自你自己动手时遇到的问题）

---

## 5. 打包版启动自检（难度：🔴 稍难 · 工程）

**背景**：打包版（PyInstaller 冻结环境）与源码运行环境有差异，曾出现"源码能跑、打包版失效"的问题（例如自改代码依赖 `.git`）。

**任务**：给打包版加一个启动自检：检测关键运行时条件（是否有 `.git`、`plugins/` 是否可写、模型目录是否存在），缺什么就在日志里明确写出**原因与补救方式**，而不是静默失败。

**涉及**：`desktop_pet.py`（启动流程）、`pet_log.py`

**验收**：
- [ ] 冻结环境下启动，日志出现自检结果（逐项 ✅/⚠️ + 原因）
- [ ] 不影响源码运行（非冻结时跳过或仅记录）
- [ ] `python -m pytest tests/` 通过
