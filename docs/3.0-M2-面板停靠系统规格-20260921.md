# 3.0 · M2 · 面板停靠系统规格（待实现，冻结 v1 草案）

> 2026-09-21 23:5x ｜ 触发：使用者意见 —— 想要 **ArcGIS Pro 那种标签页/可停靠面板**：
> 面板能**拖出成浮动窗**任意摆放，也能**停靠（吸附）**回固定位置；停靠后仍可用分隔条调大小。

---

## 一、要做的三件事（按优先级）

| # | 能力 | 说明 |
|---|---|---|
| 1 | **标签页（Tab）** | 顶部一条页签栏：`群聊流 L1` / `投递轨道 L2` / `后台总线 L3`；点页签切换主区内容（单页模式）—— 这是"以读为主"时的默认形态 ✓ |
| 2 | **浮动（Float）** | 每个面板标题栏有「⇱ 浮动」：拖出后成为**独立浮动窗**（可自由拖动位置、可调大小），仍实时刷新 ✓ |
| 3 | **停靠（Dock）** | 浮动窗上有「⇲ 停靠」，吸附回 **左 / 右 / 下** 三个槽位之一；停靠后保留**分隔条**调大小（即现状能力 ✓） |

## 二、交互细则（照 ArcGIS Pro 的手感）

- **拖动整块标题栏**即可移动：未停靠 → 自由移动；接近某个槽位边缘 → **高亮预览**，松手即停靠 ✓
- 浮动窗：标题栏拖动 + 右下角拖拽改尺寸 + 「↺ 复位」✓
- 页签栏：点页签＝主区显示该面板；「⧉ 全部显示」＝回到三栏（当前看板模式 ✓）
- **状态持久**：停靠位置/浮动坐标/面板尺寸 —— 存**内存 + URL 哈希**（不用 localStorage，避免沙箱限制 ✗）；刷新后按哈希恢复 ✓
- 键盘可达性：页签支持 ←/→ 切换、Enter 激活 ✓（无障碍底线）

## 三、实现约束（沿用已冻结的约定，不得违反）

- **`data-*` 契约不变** ✓：行级 `data-id/seq/layer/kind/sender`、L2 行 `data-cost-micro/tokens`、
  状态节点 `data-state/reason` —— 复核脚本依赖它 ✓ 重构 UI 时**必须保持** ✓
- 取数仍**只走 `/api/*`** ✓（不二次过滤/重排 ✓）
- 纯前端实现（无第三方库 ✓）：pointer 事件 + CSS 变量 + 少量 DOM 操作
- 行为退化保护：浮动/停靠系统若出错，**必须回落到"三栏固定布局"**（不能白屏 ✗）

## 四、验收（写清可机械核对）

1. 三个面板各自可**浮动 → 拖动 → 停靠**，停靠后分隔条仍可调 ✓
2. 页签切换不丢数据、不重复渲染（同一 `data-seq` 只出现一次 ✓）
3. **停靠/浮动状态**在刷新后按 URL 哈希恢复 ✓
4. `data-*` 契约扫描：重构后仍全部存在 ✓（脚本可查）
5. 出错回落：注入异常时页面仍显示三栏（不白屏 ✓）
6. 现有 63 + 8 条测试不受影响；全量退出码仍为 **0** ✓

## 五、工作量与顺序（我的估法）

- ① 页签 + 单页/全显切换（半天内 ✓，性价比最高，先做）
- ② 浮动窗（拖动 + 调尺寸 + 复位）
- ③ 停靠吸附（槽位高亮 + 落位 + 分隔条联动）
- ④ 状态持久（URL 哈希）+ 回落保护 + 契约扫描脚本

## 六、追加（2026-09-21 23:52 使用者意见）：自动隐藏 + 钉住（ArcGIS Pro 式）

**要什么**：面板**未钉住**时，鼠标移出 → 收起成边缘小条（只留标题竖条/小标签 ✓）；鼠标**移回该处** → 自动弹出 ✓；
标题栏上有个**钉子（📌）**，钉住后 → 鼠标移出也**保持展开** ✓。

### 规则（冻结）

| 状态 | 行为 |
|---|---|
| 未钉住（默认） | 鼠标移出面板区域 → 延迟 ~250ms 收起为边缘条；移入边缘条 → 立即展开 |
| 已钉住 | 移出不移出都保持展开；钉子图标高亮 |
| 收起形态 | 停在**其停靠边的边缘**（左/右/下）成一条窄条，只显示面板名（竖排或小标签）|
| 悬停展开 | 展开时**不挤压**主区内容布局抖动 ✗ → 用覆盖层（overlay）或预留占位，二者择一（实现时看效果）|
| 持久 | 钉住状态随 URL 哈希一起恢复 ✓ |

### 与停靠系统的关系（决定排期）

- **完整版**（边缘条 + 悬停展开 + 钉子）：**依于 ②③ 停靠系统** ✗ → 必须**排在 ③ 之后** ✓（否则要做两遍）
- **简化版**（只对右侧 L2/L3 面板做：收起窄条 + 悬停展开 + 钉子）：**不依赖停靠系统** ✓ → 可**单独先做** ✓

### 排期结论（我的判断）

| 阶段 | 做什么 | 何时 |
|---|---|---|
| ① | 页签 + 单页/全显切换 | 优先（性价比最高）|
| ①.5 | **简化版自动隐藏（L2/L3 边缘条 + 悬停展开 + 📌 钉住）** | 可紧随 ① 做（独立、便宜）|
| ②③ | 浮动窗 + 停靠吸附 | 其后 |
| ④ | 状态持久（含钉住） + 出错回落 | |
| ⑤ | **完整版自动隐藏**（任意停靠边） | 最后 |
