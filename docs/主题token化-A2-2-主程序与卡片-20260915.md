# 主题 token 化 · A2-2 主程序与卡片（2026-09-15）

> A2 第二段（也是最后一段）：把**主程序、代码/表格卡片、关系面板**接入主题，并建立
> **生效主题中央通道**。至此 **产品代码硬编码颜色 = 0**。

## 一、架构升级：生效主题中央通道

A2-1 时小游戏自己存了一份"主题快照"。A2-2 把它上收到 `pet_theme.py`，变成**唯一**的生效值来源：

```python
_ACTIVE_THEME = dict(DEFAULT_THEME)      # 当前生效主题（默认值 + 插件覆盖）
_WATCHERS = []                            # 订阅者

def active(): ...                         # 取当前生效字典
def color(key, fallback): ...             # 取色（唯一入口；缺键洋红兜底）
def set_active(theme): ...                # 更新 + 通知所有订阅者重刷
def subscribe(fn): ...                    # 登记"主题变化时怎么重刷"
```

各 UI 模块的接法（都是三行）：

| 模块 | 取色 | 重刷登记 |
|------|------|----------|
| `pet_minigames.py` | `T = pet_theme.color` | `pet_theme.subscribe(refresh_open)`（重刷已打开的游戏窗口） |
| `affection_ui.py` | `T = pet_theme.color` | `pet_theme.subscribe(refresh_open)`（重刷已打开的关系面板/回忆相册） |
| `chat_cards.py` | `T = pet_theme.color` | 卡片自带 `apply_theme()`，由宿主按控件登记重刷 |
| `desktop_pet.py` | `self._tk(key)` | `_apply_theme()` 末尾 `pet_theme.set_active(self.theme)` 广播 |

宿主侧新增两个小工具：
- `self._tk(key)`：宿主取色唯一入口（缺键回退唯一源）；
- `self._set_themed_qss(w, factory)`：给控件挂"按主题生成样式"的工厂，切主题时统一重刷
  （`_retheme_messages()` 新增 `kind='factory'` 分支支持）。
