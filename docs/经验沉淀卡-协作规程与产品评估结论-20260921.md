## 一、双会话协作规程（本日跑通、建议固化）

### 1. 分工铁律（避免"两边一起错"）

| 角色 | 干什么 | 不干什么 |
|---|---|---|
| **实现方**（webchat） | 写实现、写自测、管口径文档、单一写入源码/文档/记忆 | 不给自己写"验收用例" |
| **独立复核方**（微信侧） | **独立写反向/边界用例**、独立量数据、独立复核 → 出红项清单 | 不改实现、不写产品代码、不提交 |

**为什么有效（本日实证）**：复核方那 **51 条用例抓出实现方 3 个真 bug** ✗ ——
① 回合号被两个 `append` 重复推算（每步 +2）② `append` 内自动重载导致并发重号/丢 id ③ L2 投影行与 L1 正文**重复记账**（成本翻倍，等于成本闸门失效）。
→ 若同一方既写实现又写测试，这三条几乎必然带着上线 ✓

### 2. 口径纪律：**先冻结、再实现**

- 每类口径一份**冻结文档**（API 契约 / 用例设计 / UI 导出契约 / 成本对账口径），版本带日期
- 变更流程：**先喊 → 改冻结文档 → 再动实现** ✓ 事后零返工
- **一处定义、别处只引用** ✗ —— 本日踩过：插队"60s 恢复"与"绝不静默烧钱"写在两处文档，直接打架

### 3. 协调面：不依赖渠道的共享板（`workspace\COORD.md`）

动手前**先读** → 动手时**登记占用** → 收工**更新状态** → **挂定时任务前必须登记** ✓
（本日踩过：定时续跑与人工批次并行跑同一目录 ✗；使用者手机端看不到过程，不该由他判断冲突 ✓）

### 4. 排查纪律：**先二分、再理论**

本日踩过：退出码 `0xC0000005` 先按"COM/office"理论一轮 ✗ → 实际**逐文件跑一遍 2 分钟**就定位到 `tests/test_rich_copy.py`（剪贴板未清理 ✗）✓
→ 涉及"进程结束阶段""集合型"故障，第一步永远是**二分/逐文件复现** ✓

### 5. 测试纪律（本项目已验证有效）

- 涉时间的功能：**时间源必须可注入**（否则深夜跑必红、白天全绿 ✗）
- 打桩一律 `monkeypatch.setattr`（禁裸赋值，否则污染后续用例 ✗）
- "发不发请求/花不花钱"类承诺：**用调用计数器断言** ✗ 只看状态字段不够
- 自测必须含**负样本**（"证明自己会失败"）✓ 例：成本对账自测里刻意造超阈值数据，必须判不通过 ✓

### 2. 多角度定级（个人开发者标尺）

- 工程规模与组织 **B**（巨石是主要扣分）· 质量保障 **A−**（无 CI/覆盖率/类型检查）· 技术难度与自研度 **A−**
- 功能差异化 **A−**：定位 = **"可治理的 AI Agent 运行时"**（31 工具 + 治理四件套 + MCP 接入 + 平台兼容层）
- **自研度精核（严格版）**：7 项里 6 项站得住 ✓；**MCP 协议实现是官方 SDK，不得写成自研** ✗（自研的是**接入与治理层**）；"平台抽象层"建议改称**平台兼容/适配层**；小游戏不算核心创新 ✓

### 3. 差异化三条（经得起追问，可入说明书）

1. **可治理的 AI Agent 运行时**：全工具/技能/MCP 调用过权限 + 白名单 + 审计（被拒也留痕、可导出 CSV），成本按天限额
2. **技能包 + MCP 可插拔扩展体系**：目录约定 + 运行期注册 + 治理联动（同类多为源码级硬编码）
3. **透明置顶窗口上自建角色状态机与渲染管线**：DWM 透明、扒边互斥状态机、增量 markdown 渲染

### 4. 软著结论（**评估已完成，材料暂不做** ✓ 使用者 2026-09-21 定）

- **可以申请**（形式审查，不看技术水平）；免官费；材料 5 项（申请表 / 源码前后各 30 页 / 说明书前后各 30 页 / 身份证 / 权属说明）
- **六条风险按优先级**：① 名称含他人商标 **"DeepSeek"** → 建议改中性名 ② **`assets/live2d/mao` 22 文件仍被 git 跟踪且进了便携包** ✗（= 发行渠道再分发 Live2D 示例模型，必须从**仓库 + 发布包**移除）③ 立绘为 AI 生成（以**代码**为保护对象）④ 两个作者名需附同一邮箱证据 ⑤ 版本号统一（建议 V2.9 对 tag v2.9.0）⑥ 已开源被 fork 不影响登记
- 补充发现：仓库**无 THIRD_PARTY_NOTICES** 但便携包带 Qt/PySide6（LGPL）→ 建议补 LGPL 声明与获取途径 ✓

### 5. 学术可行性（同日严评结论）

**能** → 但只能到 **L2 实证**（不是 L1 新算法）。最小可交稿版本 = 《面向 AI 伙伴立绘生成的"角色一致性"度量与锚定干预有效性》：
数据 = 自产 200 张（14 模型 × 6 情绪 + 多姿势，**含锚定前后配对** ✓ 天然正负对照）；实验 = 手工度量 vs CLIP/DINOv2 嵌入度量 ↔ 双路标注（κ）＋锚定前后配对检验。
渠道优先：**arXiv 预印本 + 校级/竞赛**（零成本）；避开付费"包过"与掠夺性会议 ✗。
