02研发模式：官方主导 + 社区做生态

决定性的证据在仓库自己的 CONTRIBUTING.md 里，原文两句：

DeepSeek Harness is still at an early stage and under active development. We are sorry that we cannot accept external pull requests at the moment.
We do not believe that packages in the official repository are inherently more important than packages created by the community. You may consider this repository an idea, an official showcase, and a source of inspiration, but not a mandate from us.

代码推进官方团队自己写，目前不接受外部 PR

03更新节奏：其实很密，是"感知落差"

指标实测
发布版本数2026-08：7 个；2026-09：11 个 → 合计 18 个
每周提交最近 8 周：1,655 / 1,641 / 936 / 1,189 / 792 / 1,581 / 733（当周统计未结算，显示 0）
你装的位置0.1.5-rc.2（latest 标签）—— 而插件管理页、侧边栏 Subagent 会话等在你还没装的 0.1.6-alpha 里

所以"UI 感觉没大变化"有三个原因：① 你用的是 RC，不是最新 alpha；② 近期大量变更落在基建/治理层（CI、类型聚合、反馈流程、文件卡片），界面上看不出来；③ 官方自己把它定位成 developer preview，明说"会有破坏性变更"——功能先铺后收。

04正式版什么时候

查不到就写未查到 仓库没有公开里程碑、也没有公开的 GA/正式版时间表；官方只表态"仍处早期、活跃开发中"。 因此任何"还要几个月"的具体数字都是猜测，我不编。可观测的替代信号：继续跟 alpha → rc → 稳定 的 tag 演进，以及它是否开始接受外部 PR（一旦开放 PR，通常意味着进入收口阶段）。

05对我们 3.0 的意义

  • 官方欢迎外部"载体/插件"——它把仓库定位成"想法与展示"，明确不认为官方包天然更重要 → 我们做桌面载体、做社区式集成，正落在它鼓励的方向上。
  • 但不要押注它的内部接口：不接受外部 PR + 明说破坏性变更 → 我们的弱耦合（HTTP + 本地配置只读镜像）才是抗变化的那一侧。
  • 版本选择建议：想看到明显新东西就切 alpha 标签的 0.1.6-alpha.2（插件管理页 + 侧边栏 Subagent 会话）；想稳就留在 0.1.5-rc.2。
