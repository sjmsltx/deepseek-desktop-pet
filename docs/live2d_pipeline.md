# 🎨 自生成 2D 人物（Live2D 模型）完整流程

> 目标：为 DeepSeek V4 两个版本（Flash / Pro）制作**娘化 Live2D 模型**，放入 `assets/live2d/` 即可在桌宠菜单中选用。
> 适用：有 Photoshop 2026 + 愿意花 1-2 小时做一次手工绑定。

---

## 为什么不能"一键生成"？

Live2D 模型 = 分层立绘 + 网格绑定 + 参数动画，核心环节（绑定）必须在 **Live2D Cubism Editor**（GUI 软件）中人工完成。AI 可以辅助生成素材和拆层，但绑定环节无法全自动。

**当前立绘（全身 Q 版）不适合 Live2D**：Live2D 需要"半身/大头像、清晰五官、脸占比大"，Q 版全身脸太小，绑定后动画效果差。

---

## 流程总览

```
① 生成 Live2D 友好立绘（Seedream，提示词见下）
        ↓
② 拆层（Photoshop 2026 手工，手册见下）
        ↓
③ 绑定（Live2D Cubism Editor，手册见下）
        ↓
④ 放入 assets/live2d/<角色名>/ → 桌宠菜单选用（已完成 ✅）
```

## ① Seedream 提示词模板（生成 Live2D 友好立绘）

```text
（角色描述，二选一）
- Flash 娘化：银蓝色渐变长发、蓝眼睛、头顶小蓝鲸、浅蓝和服、人鱼尾巴
- Pro 娘化：深蓝色长发、鲸鱼元素女仆装、温柔眼神、深海主题配饰

（统一要求）
半身像构图，头部居中，脸部占画面 40% 以上，正脸微侧，清晰的大眼睛和五官；
纯白色背景，无复杂装饰遮挡脸部；边缘干净利落，方便抠图分层；
二次元赛璐璐风格，线稿清晰，色块分明，适合 Live2D 分层制作。
```

**生成后检查**：脸占图高 ≥40%、正脸、五官清晰、背景纯色。不满足就重新生成（可加"close-up portrait, upper body"）。

## ② Photoshop 2026 拆层手册（约 20 分钟）

> 目标：把一张立绘拆成 6 个独立图层组，导出 PSD。

### 步骤
1. **打开立绘** → 菜单 `选择` → `主体`（AI 自动选中人物）
2. 右键 → `通过拷贝的图层`（得到"主体"图层），隐藏原图
3. 在"主体"图层上按顺序拆出部件（每步：选区域 → 拷贝新图层 → 隐藏上层）：
   - **头发**：用 `套索工具`/`快速选择` 选中头发区域（含刘海、后发）→ 拷贝
   - **脸**：选中脸 + 耳朵区域 → 拷贝
   - **左眼**：选眼睛 → 拷贝 → 命名 `eye_L`
   - **右眼**：同上 → `eye_R`
   - **眉毛 ×2**：→ `brow_L` / `brow_R`
   - **嘴巴**：→ `mouth`
4. **图层命名**（Cubism 会按名字识别）：`body`（身体）、`face`（脸）、`hair_back`（后发）、`hair_front`（刘海）、`eye_L`、`eye_R`、`brow_L`、`brow_R`、`mouth`
5. `文件` → `存储为` → 格式选 **PSD** → 保存为 `character.psd`
6. 注意：**所有图层画布尺寸必须一致**（和原图相同），透明区域保留

### 拆层技巧
- 眼睛单独一层是 Live2D 眨眼的必要条件
- 嘴巴单独一层是说话/表情的基础
- 刘海和后发分开，方便做头发飘动

## ③ Live2D Cubism Editor 绑定手册（约 1-2 小时，首次）

### 准备
1. 下载 **Live2D Cubism Editor**（官网 live2d.com，免费版够入门；正式版订阅）
2. 下载 **Live2D Cubism SDK for Native**（免费，导出 .moc3 需要）

### 绑定步骤（概要）
1. 新建项目 → 导入 `character.psd`
2. **网格变形器**：对每个图层创建网格（选中图层 → 工具栏 `网格` → 自动生成，然后手动调整关键点贴合形状）
3. **参数绑定**（核心）：
   - 眨眼：选择 `eye_L`/`eye_R` 图层 → 参数 `EyeLOpen`/`EyeROpen` → 在时间轴上设置"睁开/闭上"两个关键帧
   - 头部转动：全选图层 → 参数 `AngleX/AngleZ` → 设置左右/上下关键帧
   - 呼吸：身体图层 → 参数 `Breath` → 上下位移关键帧
   - 嘴型：`mouth` 图层 → 参数 `MouthOpen` → 开合关键帧
4. **物理（可选）**：头发加 `Physics` 让头发自然摆动
5. **动作（可选）**：`Animation` 面板录制待机动作（呼吸/眨眼循环）
6. **导出**：`文件` → `导出为...` → Cubism 4 模型 → 得到 `<name>.model3.json` + `.moc3` + 贴图 + motions/

### 导出目录结构（必须这样放）
```
assets/live2d/<角色名>/
├── <name>.model3.json
├── <name>.moc3
├── <name>.2048/  (贴图)
├── motions/      (动作，可选)
└── expressions/  (表情，可选)
```

放好后桌宠右键 → 设置 → 显示模式 → 🤖 Live2D 模型 → 选择即可。

## 自动化程度说明

| 环节 | 自动化 | 说明 |
|------|--------|------|
| ① 立绘生成 | ✅ 全自动 | Seedream 文生图（桌宠立绘已有管线） |
| ② 拆层 | 🟡 半自动 | Photoshop 手工（20 分钟）；Python 自动拆层脚本开发中 |
| ③ 绑定 | ❌ 人工 | Cubism Editor GUI，无法自动化 |
| ④ 加载 | ✅ 全自动 | 桌宠 v6.35 模型库已支持 |

## 更快的替代（如果只想要"会动"）

如果暂时不想做完整 Live2D：用 Seedream 生成**多帧表情立绘**（闭眼/张嘴/侧脸各一张），桌宠已有的 `blink` 机制就是"局部替换"动画——把表情帧扩展成"眨眼+张嘴+转头"序列，程序化轮播，零建模成本。
