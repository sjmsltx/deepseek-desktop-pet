一、项目定位

第三方开源桌面 AI 陪伴助手（与 DeepSeek 公司无关联），双角色（V4 Flash 浅蓝人鱼 / V4 Pro 深蓝鲸鱼娘），基于官方 API。核心卖点是不只是一只宠物，而是一套完整的陪伴系统：长期记忆、情感养成、主动关心、小游戏互动、工具调用。

三、引擎开发（五套自研轻引擎）

项目没有用 Unity/Godot 等游戏引擎，而是在 PySide6 之上自研了五套「轻引擎」，每套解决一类系统性问题：

渲染层

🎭 动画引擎

静态模式：呼吸（整图缩放 1%）、眨眼（150ms 局部切换）、呆毛摆动（±8° 旋转）、尾巴（±1.5° 摇摆）；37 状态立绘随情绪切换（[emotion:happy] 标签驱动）。

Live2D 模式（v6.81）：30fps 连续动画——头部摆动 / 眨眼 / 呼吸 / 视线跟随 / 点击动作，透明 OpenGL 内嵌渲染，模型库自动扫描。

AI 层

🤖 AI 引擎

DeepSeek API + function calling 工具循环：LLM 输出意图 → 程序执行 → 结果回填。SSE 真流式（reasoning + content 分块渲染），15+ 工具（开程序 / 天气 / 提醒 / 锁屏 / 剪贴板…），危险操作需用户确认。

数据层

🧠 记忆引擎

三层记忆：对话记忆（角色隔离）+ 事实记忆（memorize 工具，重要度 + 软覆盖 + 遗忘）+ 事件记忆（回忆日志 200 条滚动）。会话摘要滚动压缩，长对话不丢关键信息。

养成层

💗 好感度引擎

双轴：好感度 0~200 + XP/等级/6 称号。五阶段人设进化（初见→灵魂伴侣），system prompt 随好感度动态注入。事件驱动纯积累制（零衰减零惩罚），三重防刷（冷却/日上限/封顶）。

调度层

⏰ 主动关心引擎

链式唤醒：AI 自调度下次唤醒（10~360 分钟钳制）+ 轻量打扰判断（空闲检测 + 深夜静默）。回访机制：对话中提到重要事件 → 定时回访主动关心（带状态感知）。

🎮 小游戏引擎（第 6 套）

注册式框架 pet_minigames.py：BaseGame 统一接口（难度下拉 / 规则说明 / 暂停保存 / 结果回调），15 款游戏（五子棋 / Farkle 骰子 / 数独 / 俄罗斯方块 / 21 点…），高分里程碑联动好感度与回忆日志。

四、总体架构

🎨 PySide6 GUI 层
透明置顶悬浮窗（FramelessWindowHint + WA_TranslucentBackground）· 立绘动画 · 聊天面板（Markdown 渲染 / 流式打字机）· 右键菜单 · 托盘 · 全局热键
▲ 信号/槽（Signal-Slot，多线程安全）
🧩 AI 核心层
system prompt（身份/性格/记忆/好感度/待办/规则）→ 工具循环（意图 JSON → 执行 → 回填）→ SSE 流式输出 · 15+ 工具 · 安全校验
▲
💾 数据层
memory.json（角色隔离记忆）· affection.json（好感度）· memories.json（回忆日志）· chat_memory.json（对话历史）· api_stats.json（API 用量）· config.json

并发模型

三线程架构：主线程（Qt UI）· AI 请求线程（DeepSeek API + SSE 解析）· 心跳/唤醒线程（主动关心调度）。跨线程一律走 Signal/Slot + QTimer.singleShot 转发，避免 Qt 跨线程崩溃。
