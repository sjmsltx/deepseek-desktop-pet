```

'记忆多到几百条以后再打开。'
```

**要做的**：docstring 加一句耦合警告；tooltip 加一句「60 token 未修前启用会导致约一半轮次不注入」。
**成本**：10 分钟。**不改行为**（开关默认关，只是把风险写清）。
