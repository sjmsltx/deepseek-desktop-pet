### 5.1 速率

| 口径 | 计算 | 结果 |
|---|---|---|
| 近 7.56 天净增 | 58 ÷ 7.56 | **7.67 次/天** |
| v3.0.2 终身均值 | 84 ÷ 11.27 天（11-02 07:33 发布） | **7.45 次/天** |

⇒ **三个口径都在 7.2~7.7 之间。** v3.0.2 的下载速率**没有衰减**，也没加速，是一条很平的线。
（三种算法：近 7.56 天净增 7.67、终身均值 7.45、上次 3.6 天窗口 7.18 —— 相互咬得上，说明数据没跳。）

### 5.2 一件反直觉的事：下载比页面浏览还多

```
v3.0.2 终身下载            84
v3.0.2 tag 页 14 天浏览    50
/releases 列表页 14 天浏览 32
```

**84 > 50。** 下载人次超过了「看着这个版本页」的人次 ⇒ 下载**不是从 tag 页点的**。
最可能的路径：`/releases/latest` 重定向（不记入 tag path 计数）+ README 里的直链。
（`tag 页 50 + 列表页 32 = 82`，与 84 只差 2 —— 数字接近，但**不能因此说「就是这么来的」**，
那只是巧合程度的问题，API 不提供点击来源。）

⚠ 也可能包含机器人/镜像的自动下载。**无法区分。**

## 十、复跑命令

```powershell
# ⚠ 本机 APPDATA 在部分 shell 里为空，gh 会报 "not logged in"，必须先补
$env:APPDATA = 'C:\Users\<你的用户名>\AppData\Roaming'
$env:LOCALAPPDATA = 'C:\Users\<你的用户名>\AppData\Local'
$gh = 'D:\ai工作站\tools\gh\bin\gh.exe'
$repo = 'sjmsltx/deepseek-desktop-pet'

& $gh api "repos/$repo" --jq '{stargazers_count,forks_count,subscribers_count,size,pushed_at}'
& $gh api "repos/$repo/traffic/views"
& $gh api "repos/$repo/traffic/clones"
& $gh api "repos/$repo/traffic/popular/referrers"
& $gh api "repos/$repo/traffic/popular/paths"
& $gh api "repos/$repo/releases?per_page=100" --jq '.[] | {tag:.tag_name, dl:[.assets[].download_count]}'
# 星标时间（必须带 starred Accept 头，否则只有 login 没有时间）
& $gh api -H 'Accept: application/vnd.github.star+json' "repos/$repo/stargazers?per_page=100"
```
