# 主题"切了不生效"诊断与修复（2026-09-15）

> 使用者实测：让桌宠"装个蓝白主题并切换"，它**装了插件、也写了 config**，但**界面毫无变化**；
> 重启后仍是默认色。要求：**让它自己能生效**（不是人工代改）。

## 一、现象与定位过程

| 检查项 | 结果 |
|--------|------|
| 插件文件 | ✅ `plugins/theme_blue_white/plugin.json` 存在，结构正确（`type: theme` + 内联 `theme` 对象） |
| 插件加载 | ✅ `plugin_mgr.theme_names()` 含它；`theme_vars()` 返回 13 个颜色（`panel_bg=#F2F7FF`） |
| 配置持久化 | ✅ `config.json` 里 `"theme": "theme_blue_white"` 已写入 |
| **界面生效** | ❌ 面板颜色从未变化 |

**⇒ 结论：数据层全对，断在"应用层"。**

## 二、三个真 bug

### Bug 1（核心）GUI 刷新投递错了
`_tool_set_theme` 里是这么"回主线程"的：

```python
QTimer.singleShot(0, self._apply_theme)   # 注释写着"线程安全"
```

但 **AI 工具是在工作线程里执行的**（`_ai_worker` → `threading.Thread` → `_execute_tool`），
而 `QTimer` 需要**目标线程有事件循环** —— 工作线程没有事件循环，**定时器永不触发**。
于是主题数据改了、config 写了、界面从未刷新。

**修法**：改用跨线程信号（项目既有做法，见 `ai_reply_signal` / `confirm_signal`）：

```python
ui_call_signal = Signal(object)      # 类级信号
self.ui_call_signal.connect(lambda fn: fn())   # 主线程执行

def _run_on_ui(self, fn):            # 统一入口：主线程直接调用，工作线程用信号投递
    ...
```

**同类问题一并修**（同一 bug 类别）：`_write_config_tool`（切语言 / 显示模式）、
`say_plain`、`_append_chat`、`_append_chat_md`。

### Bug 2 启动不恢复主题
配置读取处（`_load_ai_config`）读了 `advanced_tools`、性格、城市……**唯独没读 `theme`**，
启动流程也没有任何地方应用它 → **重启即被静默重置为 `default`**。

**修法**：`_load_ai_config` 记住 `self._saved_theme`；`_init_finish` 调 `_restore_saved_theme()`
（**必须早于历史回显**，回显出的气泡才会用主题色）。主题不存在时只记日志、不打断启动。

### Bug 3 旧消息不换色
气泡配色在创建时就写进 `QLabel` 样式表，切主题后历史消息仍是旧色 → 半截效果。

**修法**：登记受主题着色控件（`_theme_widgets`），`_apply_theme()` 末尾统一刷新；
已销毁的 Qt 对象（`RuntimeError`）自动剔除。配色规则收敛到 `pet_bubble.message_label_qss()` 单一来源。

## 三、验证证据

| 检查 | 结果 |
|------|------|
| **端到端**（真实 `config.json` 离屏构造桌宠） | ✅ `current_theme=theme_blue_white`、`theme['panel_bg']=#F2F7FF`、面板样式表含新色、默认色不再出现 |
| `pytest tests/` | ✅ **78 passed**（新增 `tests/test_theme_persist.py` 6 项） |
| `regression_test.py` | ✅ 40 / 40 PASS |
| `tests/golden_ui.py check` | ✅ 7 分区一致（theme 分区已同步为恢复后的主题） |

其中最关键的一条测试是 **`test_theme_applied_from_worker_thread`**：把 `_tool_set_theme`
放进真实的工作线程调用，再断言面板样式表里出现了新色 —— 这条在修复前**必然失败**，用来锁死这个 bug。

## 四、遗留 / 后续

- **主题切换时的流式气泡**（`_stream_label`，仅在"正在流式输出时切主题"这种边缘场景）暂未纳入刷新表。
- **小游戏 / 关系面板 / 卡片**仍未接入主题管道（见 `docs/主题待迁移清单-A2-20260915.md`，144 处）。
- **工具梯级**：`advanced_tools` 默认关时，`read_file` / `install_plugin` / `set_theme` 等不在核心 8 个里，
  会造成"AI 想改却拿不到工具"。是否把"外观/文件/插件"放回核心，待定。
