## 0. 事实约束（写实现前先记住）

- 内核**绝不自己调用真实 API**：provider **由外部注入**（回调）✓ —— 这是"数请求次数"断言（不烧钱承诺）的前提
- 时间源 **可注入**（`clock` 返回毫秒整数）✓ —— 避免"深夜跑必红"
- 排序/单调性由 **`seq`（严格单调整数）** 保证；`ts` 只作展示 ✓
- 金额一律 **微元整数（1e-6 元）** 累计与比较 ✓ 字段名统一 `cost_micro`
- 每条消息带 **schema 版本 `v`**（当前 `1`）✓

## 1. 数据结构

```python
SCHEMA_V = 1

@dataclass(frozen=True)
class Issue:                 # 议题（强制：三项缺一不可开）
    title: str               # 不能为空/纯空白
    goal: str                # 不能为空/纯空白
    done_when: str           # 结束条件，不能为空/纯空白

@dataclass(frozen=True)
class Msg:
    id: str                  # 全局唯一；重复 → 写层拒绝并告警
    seq: int                 # 严格单调递增（唯一排序/时钟无关）
    ts: int                  # 毫秒时间戳，仅展示（允许回拨）
    channel: str             # 'dm:human<->agent' | 'dm:agent<->agent' | 'group:<id>' | 'thread:<id>'
    sender: str              # 'human:<name>' | 'agent:<name>' | 'system'
    recipients: list[str]    # 空列表 = 广播
    kind: str                # speak/ask/reply/delegate/arbitrate/tool/system
    visibility: str          # human(L1) / meta(L2) / debug(L3)
    body: str                # 正文（单条上限 64 KB，超限拒绝不截断）
    meta: dict               # model, tokens, cost_micro, latency, parent_id, turn_no, v

@dataclass(frozen=True)
class ProviderReply:         # provider 回调的返回
    body: str
    tokens: int = 0
    cost_micro: int = 0
    meta: dict = field(default_factory=dict)   # 可带 model / latency 等

@dataclass(frozen=True)
class StepResult:
    ok: bool                 # 本步是否正常推进
    stopped: bool            # 是否已停（触顶/收敛/失败）
    reason: str              # '' | 'turn_limit' | 'time_limit' | 'token_limit' | 'cost_limit'
                             #      | 'converged' | 'interrupted' | 'provider_failed' | 'write_failed'
    turn_no: int             # 当前回合号（失败步不推进 ✓）
    notice_human: bool       # 是否产出了 @人类 通知
    cost_micro: int          # 本步消耗（微元）
    provider_calls: int      # 本步真实调用 provider 次数（含重试）
```

## 2. 类与签名（**冻结**）

```python
# 模块名：relay_log.py
class RelayLog:
    def __init__(self,
                 path: str | os.PathLike,        # JSONL 日志文件（不写真实用户数据；测试用 tmp_path）
                 *,
                 clock: Callable[[], int] | None = None,        # 可注入，默认 time.time()*1000
                 limits: dict | None = None,                     # 见 §3
                 provider: Callable[[Msg, Issue], ProviderReply] | None = None,  # ★ 外部注入
                 ) -> None: ...

    # --- 议题 ---
    def open_issue(self, issue: Issue) -> tuple[bool, str]:
        """议题强制：title/goal/done_when 任一为空或纯空白 → (False, '缺 <哪项>')，且 provider 调用数必须为 0 ✓"""

    # --- 写层（append-only）---
    def append(self, msg: Msg | dict) -> Msg:
        """写层规则：同 id 二次写入 → 拒绝并告警（不覆盖、不重号）✓
        单条正文 > 64 KB → 拒绝并告警（不静默截断）✓
        seq 由内核自增赋值（调用者传的 seq 被忽略）✓
        盘写入失败 → raise RelayWriteError（硬失败语义：上层须停 + @人类）✓
        """

    # --- 投递层（幂等）---
    def deliver(self, msg: Msg | dict) -> bool:
        """投递层幂等：同一 id 二次投递 → 收件箱只增一条 ✓（与写层职责分离）"""

    # --- 三层视图（同源）---
    def inbox(self, agent: str, *, layer: str = 'L1') -> list[Msg]:
        """按 agent 收件箱投影；layer ∈ {'L1','L2','L3'} 决定 visibility 过滤
        （L1=human, L2=meta, L3=debug）；同一日志三种视图条目按 id 一一对应 ✓"""

    def view(self, channel: str, *, layer: str = 'L1') -> list[Msg]:
        """按会话投影（群/私聊/线程），同样支持三层 ✓"""

    # --- 回放与对账 ---
    def replay(self, *, to_seq: int | None = None) -> list[Msg]:
        """重放；幂等（重放不产生新投递）✓；半行/坏行 → 跳过并计入 warnings ✓"""

    def cost_total(self) -> int:
        """微元整数累计 = 逐条 meta.cost_micro 求和（缺失字段计 0 但计入 warnings）✓"""

    def token_total(self) -> int: ...

    def snapshot(self) -> dict:
        """{turn_no, cost_micro, tokens, interrupted, concluded, stopped, warnings: list[str]} —— 供断言用"""

    # --- 回合推进（核心）---
    def step(self) -> StepResult:
        """推进一个回合。内部流程：
        ① 若 in interrupted：不推进、不调 provider → reason='interrupted' ✓
        ② 回合边界检查四道上限（>= 语义）：回合/时长/token/成本 → 到顶则停 + 出结论 + @人类 ✓
        ③ 调 provider（失败 → 重试 ≤ retry_max，计重试不计回合；仍失败 → 停 + @人类 ✓）
        ④ 记消息、更新成本（微元）、做结构化"主张签名"收敛检测（连续 converge_no_new 回合无新增 → 收束）
        ⑤ 触顶/收敛后 → provider_calls 不再增加 ✓
        """

    # --- 人类交互 ---
    def interrupt(self, body: str) -> Msg:
        """人类插队：最高优先级；当回合不被打断，在下一个回合边界生效 ✓
        生效后 → interrupted=True（暂停轮转），且不自动恢复 ✓"""

    def resume(self, text: str) -> bool:
        """仅当 text 为显式"继续/继续吧/continue"等白名单命令时返回 True 并恢复轮转 ✓
        回合计数不重置 ✓ 其它话语不得被视为继续 ✓"""

    def conclude(self) -> Msg:
        """产出收束结论（kind='arbitrate', visibility='human'）+ @人类 通知；重复调用幂等（只出一次）✓"""
```

## 3. `limits` 键名（**冻结**，全为关键字参数默认值）

| 键 | 默认 | 语义 |
|---|---|---|
| `max_turns` | `8` | 单议题最大回合；**回合边界检查，`>=` 即停** |
| `time_limit_ms` | `300000` | 5 分钟；**`>=` 即停** |
| `max_tokens` | `0` | `0 = 不限` |
| `max_cost_micro` | `0` | 微元；`0 = 不限` |
| `retry_max` | `2` | provider 单回合最大重试次数；超出 → 停 + @人类 |
| `converge_no_new` | `2` | 连续几回合"无新信息"判定收束 |
| `msg_max_bytes` | `65536` | 单条正文上限；超出拒绝不截断 |
| `interrupt_notice_ms` | `60000` | **仅用于"提醒一次"**；**严禁自动恢复** ✓（⭐ 原名 `interrupt_timeout_ms` → 更名，名字别再被误读成"超时后自动恢复" ✗）|

`limits` 非法值（负数、`max_turns<=0`、上限被设成 0 以外的负）→ `open_issue` 返回 `(False, ...)`，不启动、不烧钱 ✓

class RelayError(Exception): ...
